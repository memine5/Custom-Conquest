    Import cards

    Paste your card document, or choose a file. Nothing changes until you press an Import button.

    Supported formats

    Markdown or plain text. A heading starts a deck, an optional italic line under it is the tagline, and each card is a line like - **Card name** (Phase): Effect text. Phases: Draw, Move, Combat, Conquest, Reinforce, Income, Any.

    Tables. Rows with Phase, Card and Effect columns (a header row is detected). Add a Deck column to put several decks in one table.

    CSV. A header row with name, effect and phase columns, plus deck, cost and fx if you have them.

    JSON. A list of cards, or an object with decks and cards. Each card can carry name, deck, phase, text, cost, fx (effect id for later) and tags.
